# Записи о принятых решениях (ADR)

Здесь фиксируются решения, которые определили облик работы, вместе с рассмотренными
альтернативами и последствиями. Смысл записей — отделить обоснованный выбор от
случайного и сохранить причины выбора для последующего сопровождения.

Формат: контекст → решение → альтернативы → последствия. Запись не переписывается
после принятия: устаревшее решение помечается статусом «заменено» со ссылкой на новое.
