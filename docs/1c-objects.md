# Объекты 1С:Розница, лежащие в основе контракта

Референсная конфигурация — **1С:Розница 3.0**. Действующая информационная база не
подключается ([ADR 0001](adr/0001-file-exchange-instead-of-live-1c.md)); ниже перечислены объекты
конфигурации, структуру которых воспроизводит контракт файлового обмена.

| Объект 1С:Розница | В контракте | Назначение в СУЭ |
|-------------------|-------------|------------------|
| Справочник «Магазины» | `stores[]` | аналитический разрез: торговая точка |
| Справочник «Номенклатура» | `products[]` | товарный разрез и категория |
| Документ «Отчёт о розничных продажах» | `saleDocuments[]` с `documentType: "sale"` | факт реализации за кассовую смену |
| Документ «Возврат товаров от покупателя» | `saleDocuments[]` с `documentType: "return"` | уменьшение выручки и себестоимости |
| Табличная часть «Товары» документа | `saleDocuments[].lines[]` | количество, сумма, скидка |
| Регистр накопления «Себестоимость товаров» | `lines[].costAmount` | себестоимость, если она выгружена |
| — (нет в розничном контуре) | отсутствует | накладные расходы: моделируются приёмником |

## Почему «Отчёт о розничных продажах», а не «Чек ККМ»

В 1С:Розница чек ККМ — документ уровня кассовой операции; за смену их тысячи, и для
управленческой аналитики они не выгружаются. Регламентный обмен передаёт **сводку
по кассовой смене** — «Отчёт о розничных продажах», где строки уже агрегированы по
номенклатуре. Отсюда два свойства данных, заметных при просмотре пакетов:

1. Количество в строке — суммарное за смену, поэтому весовые товары имеют дробные
   значения (например, 137.5 кг), а штучные — целые (240 шт).
2. Сумма в строке — итог за смену с учётом предоставленных скидок.

Точка может иметь несколько касс, поэтому за один день допустимо несколько документов.

## Что означает `ref`

Поле `ref` соответствует GUID ссылки объекта 1С. В СУЭ он хранится как `source_ref`
и служит ключом идемпотентности: повторная передача того же пакета обновляет записи,
а не создаёт дубли. Это позволяет безопасно повторять обмен после обрыва связи.

## Чего в контракте сознательно нет

| Объект | Причина |
|--------|---------|
| Регистры взаиморасчётов, кассовые смены как отдельные объекты | не влияют на рентабельность точки |
| Скидочные и бонусные программы | скидка передаётся суммой в строке (`discountAmount`), детализация не нужна для KPI |
| НДС и налоговый учёт | рентабельность считается по выручке и себестоимости, без налогового контура |
| Движения товаров между точками | предмет работы — продажи, а не логистика |

Полное сопоставление полей — в [`mapping.md`](mapping.md), правила приёмки —
в [`exchange-protocol.md`](exchange-protocol.md).
